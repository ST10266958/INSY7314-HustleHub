# HustleHub+

Secure freelance marketplace platform developed for INSY7314.

## Project Overview

HustleHub+ is a secure freelance marketplace platform that allows freelancers to advertise services and clients to browse and book those services.

The system includes authentication, role-based access control, gig management, bookings, simulated transactions, income tracking and estimated tax calculations.
